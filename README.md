# Brasfoot 22-23 — Mod Brombila

Mod pessoal do Brasfoot 22-23 com melhorias de interface.

Este repositório guarda só os arquivos do mod (scripts e arquivos editados).
O jogo original (`BrombilaBrasfoot.exe`, imagens, sons, times, saves) **não** é versionado.

## Estrutura

Os scripts do mod (`red.js` e `build.ps1`) ainda serão adicionados.

## Como usar

1. Tenha o jogo instalado em `C:\Brasfoot22-23-Brombila`.
2. Aplique os arquivos do mod (instruções virão junto com os scripts).
